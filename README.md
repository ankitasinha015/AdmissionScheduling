# AdmissionScheduling

Patient admission scheduling with predictive bed availability.
Two day learning project. See PROJECT.md for scope and test plan.

## Data

Length of stay parameters are fitted from the MIMIC-IV demo, which is not
committed. Download it from physionet.org/content/mimic-iv-demo/2.2/ and
unzip into data/mimic/, then run: python scripts/fit_los.py

Repo: AdmissionScheduling. Python package: bedflow.
